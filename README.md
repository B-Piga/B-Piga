## 👋 Olá! Eu sou o Piga

Sou desenvolvedor **Delphi / Object Pascal** e trabalho na construção de **sistemas ERP, PDV e de gestão empresarial** — do banco de dados Firebird até a emissão de documentos fiscais e integrações com APIs externas.

Fora do Delphi, também construo **sites e aplicações web com TypeScript/React** e ferramentas em **Python**.

Estudar coisas novas é o que me move — até porque o objetivo final é virar o *véio da lancha* 🚤

- 🏢 Sistemas comerciais: ERP, PDV, delivery e gestão financeira
- 🧾 Documentos fiscais: **NFC-e** e **CF-e (SAT)**
- 🔌 Integrações: REST APIs, Bling, WhatsApp, IA (Groq)
- 🗄️ Banco de dados: Firebird e MySQL — incluindo migração entre versões do Firebird
- 🌐 Web: sites institucionais e de agendamento com TypeScript + Vercel
- 📍 Santa Cruz do Rio Pardo — SP
